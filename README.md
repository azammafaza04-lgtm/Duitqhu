DUITQHU - CARA PASANG DI IPHONE

Isi folder ini adalah aplikasi lengkap (tanpa server, tanpa akun, tanpa iklan):
  index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png
Semua file harus diunggah bersama, dalam satu folder.

1) Taruh di alamat web (HTTPS), pilih salah satu yang gratis:

   A. Netlify Drop (paling mudah, tanpa instal apa pun)
      - Buka https://app.netlify.com/drop dan masuk/daftar.
      - Seret folder ini ke halaman itu. Anda langsung mendapat alamat seperti https://nama-acak.netlify.app
      - Di pengaturan situs, ganti nama alamat menjadi yang sulit ditebak.

   B. GitHub Pages
      - Buat repositori baru, unggah semua file, lalu Settings > Pages > Deploy from branch (main, folder root).
      - Catatan: repositori gratis bersifat publik, jadi kode aplikasi terlihat orang lain. Data keuangan Anda
        TIDAK ada di sana karena tersimpan hanya di HP.

2) Di iPhone, buka alamat itu dengan SAFARI (bukan Chrome).
   Ketuk tombol Bagikan > Tambah ke Layar Utama > Tambah.
   Selanjutnya buka dari ikon di layar utama. Aplikasi tampil layar penuh dan bisa dipakai tanpa internet.

3) Pindahkan data lama dari dashboard laptop (sekali saja):
   - Di dashboard laptop klik "Ekspor cadangan" untuk mendapat file .json.
   - Kirim file itu ke iPhone (AirDrop atau iCloud Drive).
   - Di aplikasi: tab Data > Impor cadangan > pilih file > Ya, ganti.

4) Cadangan rutin (supaya aman bila HP hilang atau rusak):
   - Di aplikasi: tab Data > Ekspor cadangan > Simpan ke Files / iCloud Drive / AirDrop ke laptop.
   - Aplikasi mengingatkan bila sudah 7 hari tanpa cadangan.
   - Di laptop: dashboard > Impor cadangan > pilih file > klik Simpan. Dashboard laptop menjadi data induk.

PENTING
- Data aplikasi ada di penyimpanan Safari milik ikon layar utama. Menghapus ikon/aplikasi menghapus datanya.
  Jangan hapus sebelum mengekspor cadangan.
- Data tersimpan otomatis setiap ada perubahan (tidak perlu tombol Simpan).
- Jika nanti file aplikasi diperbarui, unggah ulang ke alamat yang sama, buka aplikasi dua kali agar versi baru aktif.
  Data tidak ikut terhapus.
